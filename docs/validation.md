# 验证范围

公开版沿用既有工作流工具与参考文档，打包时不复制旧项目档案。为防止个人审美成为所有使用者的默认值，发行版将个人 profile 改为偏好使用约定：只有当前创作者确认的偏好才参与选择。

## 可复现的工具检查

在仓库根目录运行：

```bash
python3 -B -m unittest discover -s tests -v
```

现有 19 项行为测试覆盖镜头边界、接缝和动作采样、检查原因去重、源码与媒体变化、spec 变化、计划编辑、缺失文件、空洞和重叠、越界、重复 ID、无效帧率、示例拒绝与无覆盖初始化。

可选用外部 `skill-creator` 的 `quick_validate.py` 检查 Skill 入口格式。导演判断通过实际作品与观看反馈检验。

## 图片检查

两组共八张原生 1920×1080 PNG。发布时检查原图尺寸、清单哈希与说明文档的引用，人工查看所选图片。没有以联系表或网页缩略图代替高清原图。

## 动图检查

Style Lab 的八段完整 GIF 直接从源码渲染，960×540、名义 15 fps，总时长 113 秒。逐帧解码检查尺寸、帧数、累计时长、无限循环标记与文件指纹；将已有源帧对应时刻与缩小后的 PNG 对照，另采样查看编码结果。纸艺段改为每帧独立页面完整绘制，修复复用页面时的 SVG 滤镜局部错位。GIF 有调色板及时间精度限制，高清源帧与 30 fps 源码保留。本轮检查覆盖图像与编码；配音、听感及首次观众理解情况尚待验证。

## 检查结论的适用范围

工具测试验证脚本行为。画面、讲解和声音的效果需要实际观看、听辨与观众反馈；新题材应按自己的目标验收。截图记录的是特定作品中的设计选择，复用前需确认条件是否适合。

新增经验应带触发条件、辨别原因的方法、选择与代价、验证状态，以及会改变判断的反例。未验证的修法仍是候选。
