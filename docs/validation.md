# 验证范围

公开版沿用既有工作流工具与参考文档，打包时不复制旧项目档案。为防止个人审美成为所有使用者的默认值，发行版将个人 profile 改为偏好使用约定：只有当前创作者确认的偏好才参与选择。

## 可复现的工具检查

在仓库根目录运行：

```bash
python3 -B -m unittest discover -s tests -v
```

现有 19 项行为测试覆盖镜头边界、接缝和动作采样、检查原因去重、源码与媒体变化、spec 变化、计划编辑、缺失文件、空洞和重叠、越界、重复 ID、无效帧率、示例拒绝与无覆盖初始化。

外部 `skill-creator` 的 `quick_validate.py` 可检查 Skill 入口格式；它不是本仓库运行依赖，也不验证导演判断。

## 图片检查

两组共八张原生 1920×1080 PNG。发布时检查原图尺寸、清单哈希与说明文档的引用，人工查看所选图片。没有以联系表或网页缩略图代替高清原图。

## 不作的推断

工具测试通过不等于视频好看、讲解易懂或声音自然。历史试用的文字方案不能代替实际成片观看；本仓库不把它们宣传为跨题材质量保证。截图是作品中的特定选择，不是预设风格或普适模板。

新增经验应带触发条件、辨别原因的方法、选择与代价、验证状态，以及会改变判断的反例。未验证的修法仍是候选。
