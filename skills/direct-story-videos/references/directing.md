# 叙事、转场与节奏的判断

新片规划、重构或诊断观看问题时使用。关键内容还没想清，或直接从情绪词跳到了某种拍法时，先用 [从事情本身想出画面](content-to-screen.md) 补全推导。再比较下面各方法的条件与代价。

## 叙事：观众在经历什么

先明确本片希望观众理解、感受、观察或采取什么行动；他已知多少，什么必须说清，什么可以保留歧义。可以让原因、角色处境、视觉发现、声音体验或比较本身组织作品，不默认每支片子有问题—灾难—解法。

| 当前观看需求 | 可采用的组织方式与理由 | 代价或改选条件 |
| --- | --- | --- |
| 理解陌生机制 | 按必要前提逐步展示变化，使结果可归因 | 受众已熟悉时从关键差异或结果进入，避免重复基础 |
| 追随人的经历 | 围绕行动、选择和遭遇组织，允许有意义的停留 | 若人物只是装饰或素材不足，改由过程、证据或观察组织 |
| 自己发现关联 | 适量隐去信息，用并置、线索、揭示让理解发生 | 先提供辨认对象和关系所需的线索，再决定哪些信息适合延后 |
| 比较两个方法或状态 | 保持可比较的尺度、条件与观察维度 | 若同时比较太难，分段；若比较本身是假关系，不用剪辑制造因果 |
| 沉浸、观察或体会 | 按空间、感官、质感、重复或持续时间组织 | 若停留没有产生本片所需体验，再压缩或换观察位置；不机械加冲突 |

这些方式可组合。开场可以直接回答问题、进入动作、先给结果、留一个缺口或让观众停留；选择依据是本片观众进入体验所需的线索。结尾可以收束、开放、循环、停在动作中或给行动入口，按任务决定。

## 信息怎样分配

关键段落只记录必要的几项：观众实际接收到哪些线索、可据此推断什么、哪些未知是有意保留的。角色存在时再比较角色与观众知道多少：先知道危险可以产生悬念，同时发现可以产生意外，事后追认可以产生重新理解；没有角色的作品不需造一个主角。

新术语需要受众已有知识或可辨认的指代，不靠标题自动建立理解。抽象作品可以依靠形状、关系与声音；解释现实机制时仍不能改变事实。若采用重演或反事实比较，应给出足够线索区分真实发生与假设。

在粗剪或关键样片阶段，若需验证理解，让未读脚本的人先看，再复述发生了什么、依据哪些线索、哪里疑惑；不要先告知正确答案。体验型作品可问记住了什么、注意和感受怎样变化，不强求复述因果链。没有首次观看证据时，作者判断仍是待验证假设。

## 重复、伏笔和回扣

先问重复承担什么：推进信息、比较差别、建立节律、仪式、稳定感或感官停留都可成立。只有在本片目的下没有作用时才删减。不能用日期或状态标签直接宣布某种情绪已经形成。

需要观众认出回扣时，保留足够的物体、位置、动作或声音特征；变化服务这次再现的意义。几何相同不证明观众记住过。按本片需要选择伏笔、高潮、回扣与主题句，并检验它们是否实际有效。

## 转场：先判断两段是什么关系

先看进入点和离开点，再选是否剪切及如何剪切。记录观众应保留什么、可以放下什么、该察觉什么变化。比较桥接、普通硬切和保留长镜头，选择最适合当前关系的一种。

| 两段关系／目标 | 可以考虑 | 检查的风险 |
| --- | --- | --- |
| 同一动作或视线延续 | 连续镜头、动作切、视线切；需要时保留方向与位置线索 | 无意跳位、动作重做、视线找不到对象 |
| 时间省略或过程压缩 | 硬切、跳切、蒙太奇、叠化、时间线索，按内容选择 | 被误读为同时发生、动作不可能在省略时间内完成 |
| 对照、联想或因果解释 | 并置、匹配、连接动作或解释线索 | 形状相似被误当同一对象，先后镜头被误当因果 |
| 预感、情绪留尾或主观联系 | J-cut、L-cut、声音母题或声音与画面的有意错位 | 提前泄露、失去声源辨认，掩盖了真正缺失的关系 |
| 惊讶、喜剧、疏离或段落分隔 | 明显硬切、骤断、黑场、字幕或刻意不连续 | 断裂只有刺激而没有本片用途；误伤需理解的信息 |
| 需要持续观察或保留表演 | 不切，或等实际动作／声音到合适节点再切 | 为了“有节奏”打断体验，或不必要地延迟离开 |

根据本片目的判断切换应当平顺还是可被察觉，并说明它与当前内容的关系。不同镜头不必总有同一个物体；若确需追踪身份，则不能无意丢失。

连同切点前后的短片段一起复查：是否知道需要知道的地点、时间和关系？故意跳跃是否产生预期效果？叠化和运动转场还要看中间态的双主体、文字重叠与层级；首尾漂亮不够。

## 节奏：先找本段由什么决定时间

在关键段落辨认主要时间依据：阅读／理解、完整动作或表演、音乐句法、对话、期待与反应，或观察／聆听本身。它可以逐段变化；协调其他层，不默认旁白、音乐或剪辑中的任何一层永远领先。

- **信息复杂或陌生：** 给识别、比较和理解时间；可调整同时出现的信息量与片长。熟悉信息或重复示范可省略，但保留必要因果。
- **动作与表演：** 检查准备、发生和余波中哪些部分承载意义。需要重量或反应时留足；需要省略时可以跳过，不必所有动作演完整。
- **音乐或声音组织：** 根据乐句、重音、延续和休止决定关系；顺拍、切分、跨拍或静止都有用途，不要求每拍都切。
- **期待、喜剧或冲击：** 调整观众形成预测和得到回应的间隔；具体时间用片段试验，不套固定几帧或统一加速曲线。
- **观察、仪式或沉浸：** 静止、重复、均匀和持续聆听可以就是内容。通过实际观看决定停留时长，以及是否需要新信息或动作。

需要集中情绪时分配强弱与高潮；循环、多中心、均匀或开放结构可以没有主峰。紧张未必更快，轻松未必更慢，短片也未必每秒换镜头。停留是否过长取决于观众还在经历什么，不能由镜头秒数独立裁决。

有固定时长时重选内容范围、信息密度与表现方式；允许有意快读或变速，但不能因沿用旧时轴而损坏必要信息和表演。用有代表性的片段比较节奏，仅在会改变决定的地方试不同方案。

## 判断与验证

把取舍简记为“本段条件—采用方法及代价—怎样检验”；条件变化再重审。参考技法入口见 [判断方法](judgment.md)，视觉选择见 [视觉判断](visual-direction.md)，声音分工见 [声音](sound.md)。静帧可查构图，原速片段才可查节奏；用实际片段与观看反馈检验所选技法的效果。
