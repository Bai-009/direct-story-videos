# 质检：按当前作品目标验收

## 先确定验收对象与适用标准

读当前 brief、观看条件和设计依据，确认正在检查的是何种理解或体验、哪些事实与交付要求必须满足。合理的歧义、骤断、抽象运动、遮蔽或静默不能因不符合另一类作品的习惯而被修掉；声称是设计也不能替代效果证据。

记录主入口／版本、时长、帧率、尺寸和实际源码／媒体输入。历史检查只能提示风险。只读评审就交发现；被授权修复时再修改。

需要采样计划时可用 `video_workflow.py plan SPEC`；`verify PLAN` 核对明确列出的输入。它不发现所有依赖，不播放、不听辨、不评价审美，所列人工检查按本片适用性选择。计划与实际完成的观看检查分别记录。

## 选择能回答当前问题的检查方式

| 方式／范围 | 能回答什么 | 条件和边界 |
| --- | --- | --- |
| 剧本、素材与事实核对 | 是否符合意图，主张和因果是否有依据 | 体验型作品不强制讲出因果链；文字自洽不证明成片成立 |
| 目标条件下原速观看 | 整体理解、感受、节奏和实际声画关系 | 静音传播与有声沉浸用不同条件；检查实际请求的版本 |
| 静音看画面 | 视觉层级、动作、字幕与静音版本的信息 | 声画互补作品不要求静音也完整表达；此时只是诊断工具 |
| 单独听声 | 听觉信息、节奏、表演、空间或混音 | 无声片不适用；有声片也不一定只听就能理解全片 |
| 切点两侧及上下文 | 连续或不连续是否达到目的 | 按当前目的检查平顺或断裂的效果；过渡中间态另查交叠与空洞 |
| 动作／图形关键时点 | 对应世界规则、身份、状态和层级 | 真实动作查接触和物理，图形变形查映射，风格化查其规则 |
| 原尺寸与目标观看尺寸 | 小字、焦点、细节和安全区域 | 联系表只能筛查构图；非关键纹理不必逐字可读 |
| 自动测量与最终文件 | 时间、格式、音频、布局、归档等可量化错误 | 不证明听感、审美、首次理解或用户认可 |

整片审查覆盖全部段落及实际存在的声画层；局部修订按影响范围复验。静帧采样深度由风险决定，不用截图数量作为质量分数。可见性测量应排除屏外、被遮挡或有意失焦的内容，视觉关系仍需看实际画面。

## 按后果排序问题

1. **意图、事实与交付：** 是否改写当前意思、虚构能力、遗漏明确要求或交付无法使用的文件？
2. **目标观看体验：** 本片需要理解的关系是否成立，需要保留的歧义是否有意义，停留／节奏是否达成目的？
3. **表现规则：** 当前作品的身份、状态、空间与运动规则有无无意矛盾？
4. **视觉与声音选择：** 是否由本片条件推出，还是沿用别片；各层组合与主次是否适配？
5. **实现与细节：** 拼接、排版、裁切、音频、编码或资源问题是否损伤上述目标？

不能用统一偏好验收所有作品：信息片看不懂可能是关键失败，观察片不提供解释未必有问题；自然对话和刻意机械播报、同步拟音和讽刺错位也各有适用条件。疑似“有意”但效果未证实时记录为待验证，不替作者自动辩护。

## 让验证能推翻作者判断

对关键理解或体验，尽早让未读脚本的人看粗剪／片段，记录其实际复述、注意和疑惑，再对照目标；不先提示正确答案。独立模型只有具备相关观看／听辨能力时才能提供那一层判断，不能冒充真人反馈。

无法取得首次观看反馈或实际听感时继续可验证工作，保留限制；作者合理推断、独立评审、自动测量与用户认可分别记录。

## 记录与证据失效

每条问题记录“位置—实际现象—与本片目标的冲突—根因候选—处理及代价—复验证据”。适用项目用已查／失败／待查；不适用项写本片条件，例如“无旁白，无人声拼接”。无需为填表添加声部或剧情。

意图、结构、时轴、共享几何／状态、字幕／母带、字体／素材或编码变化，使相应旧证据失效。重查受影响镜头、前后关系、共享调用及对应声画；有全局影响才扩大到全片。不要无理由重复全量检查。

交付分别列出源码／预览／完整媒体是否存在、检查对象与范围、实际修复、剩余限制。技术通过不能写成“用户满意”，源帧通过不能写成“全片已播放”，配置了导出命令不能写成“MP4已交付”。
